# 기능 명세

## 1. 화면 구성

탭 5개로 간다. 1.x 의 서랍 메뉴는 버린다. 서랍은 채널 목록 하나만 담고 있었는데, 2.0 은 추천·라이브러리·프리셋이 각각 독립된 화면이라 서랍에 넣을 수 없다.

| 탭 | SF Symbol | 역할 |
| --- | --- | --- |
| 추천 | `sparkles` | 지금 상황에 맞는 채널·에피소드 목록 |
| 탐색 | `magnifyingglass` | 국가·장르·언어별 찾기, 검색 |
| 프리셋 | `square.grid.2x2` | 상황 프리셋 목록과 편집 |
| 기록 | `chart.bar` | 청취 기록, 월간 리포트 |
| 설정 | `gearshape` | 알람, 타이머 기본값, 버전 |

재생 화면은 탭이 아니라 **화면 아래에 붙는 미니 플레이어**다. 탭하면 전체 화면으로 올라온다. 미니 플레이어는 어느 탭에서나 보인다.

아이콘은 전부 SF Symbols 를 쓴다. 이모지는 쓰지 않는다.

## 2. 재생

### 2.1 공통 동작

- `AVAudioSession` 카테고리 `.playback`. 무음 스위치와 무관하게 소리가 나고 백그라운드에서 이어진다.
- `UIBackgroundModes = audio`.
- 잠금화면·제어센터에 채널명·프로그램명·아트워크를 올린다(`MPNowPlayingInfoCenter`).
- 원격 명령은 재생·일시정지·다음·이전(`MPRemoteCommandCenter`).
- 전화 등 인터럽트가 끝나면 `shouldResume` 일 때만 재생을 잇는다.

### 2.2 인터넷 라디오

스트림 주소는 프록시가 준다. 앱은 `AVPlayer` 에 URL 을 넣는 것만 한다. `.pls` 파싱, HTML 긁기, 리다이렉트 추적은 전부 프록시가 처리한다.

라디오는 길이가 없으므로 진행 바를 쓰지 않는다. 재생 경과 시간만 표시한다.

Shoutcast·Icecast 계열 스트림은 ICY 메타데이터로 지금 나오는 곡명을 보낸다. `AVPlayerItem` 의 timed metadata 로 받아 표시한다. 방송국마다 지원 여부가 다르므로 없으면 채널명만 보여준다. 실제로 얼마나 잡히는지는 M1 에서 실측한다.

**스트림이 죽었을 때**를 반드시 다룬다. 인터넷 라디오는 조용히 죽는다. 15초 안에 첫 오디오가 나오지 않으면 실패로 보고, 사용자에게 "이 채널이 응답하지 않는다"를 알리고 프록시에 신고한다. 신고가 쌓인 채널은 추천에서 빠진다.

### 2.3 팟캐스트

에피소드는 길이가 있으므로 진행 바, 15초 되감기, 재생 속도(1.0/1.2/1.5/2.0), 이어듣기 위치 저장을 넣는다.

다운로드는 2.0 범위에 넣지 않는다. 스트리밍만 한다.

### 2.4 히든 라디오

한국 지상파다. 채널 목록과 지금 방송 중인 프로그램·앨범아트를 프록시에서 받는다. 프로그램 종료 시각이 있으므로 진행 바를 쓴다.

히든 기능 해제 방식은 1.x 의 "버전 라벨 40회 탭"을 그대로 쓰지 않는다. 해제 직후 `exit(0)` 으로 앱을 강제 종료하는 동작은 애플이 금지한다. 2.0 에서는 탭 횟수를 12회로 줄이고, 해제되면 앱을 끄지 않고 **탐색 탭 맨 위에 '라디오' 섹션**이 나타나는 방식으로 바꾼다. 여섯 번째 탭으로 두지 않는다. iOS `TabView` 는 탭이 다섯 개를 넘으면 '더 보기' 탭으로 접어 버린다.

## 3. 상황 프리셋

프리셋 하나가 담는 것.

| 필드 | 예 |
| --- | --- |
| 이름 | 취침 |
| 아이콘 | `moon.zzz` |
| 소스 | 채널 ID 또는 팟캐스트 피드 ID, 또는 "추천에서 자동 선택" |
| 타이머 | 45분, 페이드아웃 30초 |
| 볼륨 | 시작 볼륨 지정(선택) |
| 이어서 | 첫 소스가 끝나면 다음 소스로 넘김(선택) |

기본 프리셋 5개를 처음 실행 때 만들어 둔다. 취침 · 운전 · 공부 · 작업 · 기상. 사용자가 이름과 내용을 바꿀 수 있고 새로 만들 수도 있다.

**소스를 "자동 선택"으로 두는 것이 이 앱의 핵심 동작이다.** 취침 프리셋을 탭하면 그 시각·요일·내 기록에 맞는 채널이 골라져 바로 재생된다. 매번 목록을 뒤지지 않는다.

## 4. 자동 종료 타이머

1.x 에도 있던 기능이고 이 앱의 원래 정체성이다. 다음을 고친다.

- 슬라이더 대신 **프리셋 버튼**(15 · 30 · 45 · 60 · 90분)과 직접 입력을 함께 둔다.
- **페이드아웃**을 넣는다. 지금은 시간이 되면 뚝 끊긴다. 마지막 30초 동안 볼륨을 0 으로 내린다.
- "이 에피소드 끝까지" 옵션을 팟캐스트에 넣는다.
- 남은 시간을 미니 플레이어에 표시한다.
- 타이머 구현을 하나로 모은다. 1.x 는 타이머가 7개고 서로 무효화하는 순서가 흩어져 있었다.

## 5. 알람

### 5.1 iOS 제약을 먼저 적어 둔다

**푸시가 와도 앱이 저절로 소리를 내지는 못한다.** 원격 알림은 사용자가 탭해야 앱이 열린다. 조용한 푸시로 앱을 깨워도 그 시점에 오디오 세션을 켜서 재생을 시작하는 것은 허용되지 않는다. 1.x 가 "앱을 완전히 종료하지 마세요" 라는 알림을 보내던 이유가 이것이다.

2.0 은 이 제약을 인정하고 설계한다. 탭 한 번은 남는다.

제약이 둘 더 있다.

- **무음 스위치와 벨소리 볼륨을 따른다.** 알림음은 벨소리 볼륨으로 나고, 무음 모드면 소리가 안 난다. 이를 뚫는 Critical Alerts 는 애플 승인이 필요한 별도 엔타이틀먼트라 2.0 에서는 신청하지 않는다. 알람 설정 화면에 "무음 모드에서는 알람 소리가 나지 않는다"를 명시한다.
- **알림음은 한 번만 난다.** 최대 30초짜리 사운드가 한 번 재생되고 끝난다. 시계 앱처럼 끌 때까지 반복하지 않는다. 그래서 알람 시각 5분 뒤에 스누즈 로컬 알림을 미리 예약해 두고, 사용자가 알림을 탭하거나 앱을 열면 취소한다.

### 5.2 동작

| 요소 | 내용 |
| --- | --- |
| 알림음 | 최대 30초 커스텀 사운드. 일반 알림음이 아니라 알람처럼 울린다 |
| 본문 | 서버가 발송 시점에 채운다. "KBS 쿨FM · 지금 〈볼륨을 높여요〉 방송 중" |
| 액션 버튼 | 잠금화면에서 **재생**을 누르면 앱이 열리며 그 소스가 바로 시작된다 |
| 알림 탭 | 같다 |
| 다시 알림 | 5·10분 스누즈 |

### 5.3 서버 푸시 + 로컬 백업

서버 푸시를 쓰는 실익은 두 가지다. 발송 시점에 편성표를 조회해 "지금 무슨 방송인지"를 본문에 담을 수 있고, 알람 설정이 서버에 남아 기기를 바꿔도 유지된다.

대신 서버가 죽으면 알람이 통째로 안 온다. 그래서 **로컬 알림을 백업으로 함께 예약한다.** 서버 푸시가 먼저 도착하면 로컬 알림을 취소한다. 로컬 알림 본문은 편성표 없이 "알람 · 취침 프리셋" 수준으로 단순하게 둔다.

요일별 반복은 1.x 처럼 요일마다 식별자를 따로 두는 방식을 유지한다(`UNCalendarNotificationTrigger` 는 요일 하나만 받는다).

## 6. 청취 기록

재생이 시작되면 세션이 열리고, 끝나거나 다른 소스로 넘어가면 닫힌다. 저장하는 값.

- 소스 종류(라디오·팟캐스트·히든), 소스 ID, 제목
- 시작 시각, 재생 시간
- 어느 프리셋에서 시작했는지, 추천에서 골랐는지
- 30초 안에 넘겼는지 (추천 품질 신호)

전부 기기 안(SwiftData)에만 둔다. 서버로 보내지 않는다. 개인화 재정렬도 기기에서 한다.

월간 리포트는 이렇게 보인다. "9월에 152시간. 가장 많이 들은 것은 Jazz24. 취침 프리셋을 24일 썼다."

## 8. 접근성·기타

- Dynamic Type 지원. 1.x 는 폰트 크기를 코드에 고정했다.
- VoiceOver 라벨을 재생 컨트롤과 채널 목록에 붙인다.
- 다크 모드 기본. 라이트 모드도 지원한다(1.x 는 검정 배경 고정).
- 세로 고정. 1.x 와 같다.
- 언어는 한국어와 영어.
