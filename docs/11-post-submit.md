## 알람 전달 경로

**iOS 26 이상은 AlarmKit 하나만 쓴다.** 시스템 알람이라 무음 모드와 집중 모드를 뚫고,
잠금 화면 단추를 누르면 앱 화면이 열리지 않은 채 실시간 방송이 시작된다.
iOS 25 이하는 지금까지의 길 — 서버 푸시 + 로컬 백업 알림 — 그대로다.

길을 가르는 곳은 `AlarmDelivery` 한 곳이다.

| 파일 | 하는 일 |
| --- | --- |
| `Sources/Core/Notifications/AlarmDelivery.swift` | 어느 길로 갈지 정한다 |
| `Sources/Core/Notifications/AlarmKitScheduler.swift` | 알람을 2분 간격 4개 연쇄로 걸고 치운다. 권한도 여기서 묻는다 |
| `Sources/Core/Notifications/AlarmIntents.swift` | 알람 화면의 `끄기`·`방송 켜기` 단추 |
| `Sources/Core/Notifications/AlarmPlaybackBridge.swift` | 화면 없이 재생기를 부르는 통로 |

`project.yml` 에 `NSAlarmKitUsageDescription` 과 `NSSupportsLiveActivities` 를 넣었다.
사용 설명이 비어 있으면 알람을 아예 걸 수 없다.

### 두 번 깨우던 문제

시스템 알람과 서버 푸시, 로컬 백업 알림이 같은 시각에 함께 오면 두 번 이상 깨운다.
세 곳에서 막는다.

1. `AlarmDelivery` — 길을 한 곳에서 정한다
2. `AlarmStore.reschedule` — AlarmKit 으로 가면 `LocalAlarmScheduler.cancelAll()` 로 로컬 백업을 치운다
3. `PushRegistrar` — AlarmKit 으로 가면 서버 푸시 토큰을 지운다. 서버가 보낼 대상 자체가 없어진다

토큰을 지웠다는 표시(`zp.push.droppedForAlarmKit`)는 **되돌릴 수 있어야 한다.**
알람 권한을 껐다 다시 켜면 그 사이에 토큰이 다시 올라가는데, 표시가 남아 있으면
두 번째로 켤 때 토큰을 지우지 않아 중복이 되살아난다. 그래서 토큰을 올릴 때 표시를 턴다.

권한을 받은 **그 자리에서** 토큰을 지운다. 다음에 앱을 열 때까지 기다리면
그 사이에 걸린 첫 알람이 두 번 울린다.

## 알람음

애플이 주는 선택지는 `sound: .default` 아니면 `.named(우리 파일)` 둘뿐이고 **음량 인자가 없다.**
시계 앱의 알람 벨소리 9종은 private framework 안에 있어 앱이 읽을 수 없다.
그래서 목록을 이렇게 짰다.

| 고른 것 | 어떻게 울리나 | 음량 |
| --- | --- | --- |
| 기본음(첫 줄, 기본값) | 끌 때까지 반복한다. 가장 크다 | 기기의 벨소리 볼륨 |
| 고전 멜로디 20곡 | 22.5~29.0초가 한 번 울린다. 2분 간격 연쇄가 이를 메운다 | 슬라이더로 조절 |

**음원은 우리가 연주해 구웠다.** 저작권이 끝난 곡을 FluidR3 GM 사운드폰트(MIT)로
렌더링했으므로 녹음의 권리자가 우리다. 만드는 도구와 권리 정리는 `tools/alarm-tones/` 에 있다.

번들에는 IMA4 압축 CAF 로 담았다(20곡 12MB). 기기에서 링형 PCM WAV 로 풀어
`Library/Sounds` 에 쓴다. 캐시 파일 이름에 **번들 파일 크기를 붙여** 두었다 —
음원을 다시 구우면 이름이 바뀌어 저절로 새로 굽는다. 사람이 판 번호를 올려 주는 방식은 쓰지 않는다.

## 재생

**인터럽트 뒤 복구에 구멍이 둘 있었다.** 둘 다 멀쩡한 방송국을 죽은 것으로 서버에 신고하게 만들었다.

- 첫 소리가 나기 전에 전화가 오면 `.began` 을 흘려보내 15초 워치독이 그대로 돌았다.
  이제 로딩 중 인터럽트는 워치독을 세우고, 끝나면 처음부터 다시 건다
- 긴 통화 뒤에는 기존 `AVPlayer` 에 `play()` 만 불러도 라이브 스트림이 붙지 않는다.
  끊긴 시간이 60초를 넘으면(`liveReconnectThreshold`) 연결을 새로 연다

## 화면

- **즐겨찾기 하트를 빨강 하나로 맞췄다.** 목록에서는 분홍, 재생 화면과 탐색 탭 토글에서는
  색이 없었다. 값은 `Sources/Core/UI/AppColor.swift` 한 자리에 둔다
- 알람음 목록은 줄 어디를 눌러도 골라진다. `.buttonStyle(.plain)` 은 터치를 글자에만
  거는데, `.contentShape` 를 단추 **라벨 안쪽**에 두어야 줄 전체가 잡힌다
- **설정에 '오픈소스 라이선스' 를 넣었다.** 알람음을 구울 때 쓴 사운드폰트가 MIT 이고,
  MIT 는 저작권 표시와 허가 문구를 사본에 포함하라고 요구한다. 구운 음원이 그 샘플에서
  나왔으므로 앱 안에 원문을 그대로 싣는다(`Sources/Features/Settings/LicensesView.swift`)

## 조사만 하고 고치지 않은 것

**썸네일 갱신은 소스 종류마다 다르다.** 버그가 아니라 정보가 있는 곳과 없는 곳의 차이다.

| 종류 | 프로그램이 바뀔 때 |
| --- | --- |
| 지상파 | 갱신된다. 편성표를 60~1800초마다 다시 받는다(주기는 서버가 정한다) |
| 일반 라디오 — ICY 를 주는 곳 | 갱신된다. 곡 이미지가 오면 바로 바꾼다 |
| 일반 라디오 — ICY 가 없는 곳 | 안 바뀐다. 서버에 그 방송의 편성표가 없다 |
| 팟캐스트 | 안 바뀐다. 에피소드 그림이라 그게 맞다 |

## 서버

`server/src/routes/alarmSound.ts` 를 만들었지만 **경로를 걸지 않았고 배포도 하지 않았다.**
방송 앞 25초를 잘라 알람음으로 내려주는 길인데, 커스텀 알람음이 한 번만 울리고
기본음보다 작게 들려서 접었다. 파일 머리말에 다시 열 때 주의할 점을 적어 두었다.

## 검증 상태

실기기는 iPhone 18 Pro Max / iOS 27.0 이다.

**확인한 것**

- 앱을 강제 종료해 둔 상태에서 알람이 제시간에 울린다
- 알람 화면 단추를 누르면 앱 화면이 열리지 않은 채 실시간 방송이 재생된다(소리까지 확인)
- 20곡이 기기에서 44100Hz 로 구워진다(`-ZPBakeTones 1`)
- 음원을 바꾸면 옛 캐시가 치워지고 새 파일로 바뀐다
- 사용자가 알람이 울리는 것을 직접 확인했다

**아직 확인하지 않은 것**

- 새 44.1kHz 음원으로 실제 알람을 울려 소리를 듣는 것
- 알람음 목록에서 줄의 빈 칸을 눌러 골라지는 것
- 자정을 넘는 연쇄(23:54 이후 알람). 요일까지 밀어야 해서 지금은 건너뛴다

## 랜딩 페이지

`zeroplayer.zerolive.co.kr` (저장소의 `worker/`) 을 다시 짰다. 두 가지가 이유다.

**사실이 틀려 있었다.** 알람 설명이 2.0 기준이라 "무음 모드에서는 울리지 않는다" 로 적혀
있었고, 판 번호가 2.0 이었고, 방송국 수가 실제(사천구백여 곳)와 맞지 않았다. 알람음 스무
곡은 아예 없었다. 지금은 앱·서버 코드에서 확인한 값으로 맞췄고, 어느 파일에서 온 값인지를
`worker/src/content.ts` 머리말에 적어 두었다 — 앱을 고치면 그 목록을 따라 함께 고친다.

**모양이 템플릿 같았다.** 섹션마다 대문자 배지를 얹고, 기능을 여섯 장의 카드로 늘어놓고,
카드가 마우스를 따라 들렸다. 규칙을 세워 다시 짰다. 배지를 쓰지 않고, 테두리 상자 대신
머리카락 선과 여백으로 나누고, 어두운 구역은 알람 한 곳만 두었다. 규칙은
`worker/src/styles.ts` 머리말에 있다.

**실제 앱 화면을 넣었다.** `Screenshots/` 의 캡처를 줄여 `worker/public/assets/shots/` 에
두었다(한국어·영어 각 5장, 합쳐 209KB, 히어로 한 장만 즉시 받고 나머지는 lazy).

알람 캡처는 새로 찍었다. 2.0 때 찍은 것에는 화면 아래에 "무음 모드에서는 알람 소리가 나지
않습니다" 가 적혀 있어 페이지 설명과 정반대였다. 시뮬레이터를 `erase` 한 뒤
`-ZPNoAds 1 -ZPFakePushGranted 1 -ZPSeedAlarm 07:00 -ZPStartTab alarm -ZPOpenAlarms 1` 로
다시 찍어 `Screenshots/{ko,en}/08-alarm.png` 도 함께 갈았다.

그 밖에 고친 것.

- 나비게이션 아이콘이 옛 CloudRadio 아이콘이었다. 지금 앱 아이콘(ZERO PLAYER)으로 바꿨다
- `llms.txt` 의 알람 설명과 방송국 수를 갱신하고, iOS 26 이상에서 푸시 토큰을 지운다는 것을 적었다
- 개인정보처리방침과 문의 문서의 알람 절을 두 갈래(iOS 26 이상 / 25 이하)로 다시 썼다
- 좁은 화면에서 언어 전환이 로고 옆에 붙던 것을 오른쪽 끝으로 옮겼다

**아직 배포하지 않았다.** `cd worker && npm run deploy` 로 올린다.
