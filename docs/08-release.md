# 출시 준비

App Store 에 2.0 을 올리기 전에 채워야 하는 것을 모은다. 코드가 아니라 콘솔에서 하는 일이 대부분이다.

## 1. App Store Connect 에 넣는 값

버전 정보에 딸린 값이라 새 버전을 제출해야 바뀐다. 1.7 은 이 칸이 전부 비어 있다.

| 칸 | 값 |
| --- | --- |
| 마케팅 URL | `https://zeroplayer.zerolive.co.kr` |
| 지원 URL | `https://zeroplayer.zerolive.co.kr/support` |
| 개인정보처리방침 URL | `https://zeroplayer.zerolive.co.kr/privacy` |

**마케팅 URL 이 AdMob 앱 인증을 푼다.** AdMob 은 App Store 앱 페이지의 '개발자 웹사이트'
를 읽고 그 도메인의 루트에서 `/app-ads.txt` 를 찾는다. 그 값이 곧 마케팅 URL 이다.
지금 비어 있어서 크롤할 곳이 없고, 그래서 인증이 '찾을 수 없음' 에 멈춰 있다.
2.0 이 스토어에 반영된 뒤 AdMob 에서 다시 확인을 누르면 풀린다.

## 2. App Privacy 표기

### 2.1 앱이 직접 보내는 것

| 항목 | 분류 | 쓰는 곳 | 사용자에 연결 | 추적 |
| --- | --- | --- | --- | --- |
| 설치 UUID | 식별자 → 사용자 ID | 알람 등록, 히든 해제, 남용 차단 | 예 | 아니요 |
| APNs 기기 토큰 | 식별자 → 기기 ID | 알람 푸시 발송 | 예 | 아니요 |
| 알람 설정(시각·요일·소스) | 사용자 콘텐츠 → 기타 | 앱 기능 | 예 | 아니요 |
| 재생 실패 신고(방송국 번호) | 진단 → 기타 | 죽은 방송국 걸러내기 | 아니요 | 아니요 |

설치 UUID 는 기기 식별자가 아니라 앱이 처음 실행될 때 만들어 키체인에 넣는 값이다.
앱을 지웠다 깔아도 키체인에 남을 수 있어 **'사용자 ID' 로 표기한다.**

### 2.2 기기에만 있고 서버로 보내지 않는 것

청취 기록, 즐겨찾기, 프리셋, 이어듣기 위치, 추천 품질 지표. 전부 SwiftData 에만 있다.
**App Privacy 에 적지 않는다** — 수집하지 않기 때문이다. 개인정보처리방침에는 명시한다.

### 2.3 AdMob 이 가져가는 것

광고 SDK 가 수집하는 항목은 앱이 정하는 것이 아니다. 제출 직전에 구글이 공개한
'AdMob SDK 데이터 공개' 문서를 그대로 옮긴다. 2026-09 기준으로 적어도 다음이 들어간다.

- 식별자 → 기기 ID (IDFA·IDFV). **추적 목적**
- 사용 데이터 → 제품 상호작용, 광고 데이터
- 위치 → 대략적인 위치
- 진단 → 크래시·성능 데이터

추적 목적이 하나라도 있으면 ATT 허가창이 필요하다. 문구는 `project.yml` 의
`NSUserTrackingUsageDescription` 에 있다.

## 3. 심사에서 미리 말해 둘 것

**히든 라디오를 심사 메모에 반드시 적는다.** 애플 심사 지침 2.3.1 은 숨겨진 기능과
문서화되지 않은 기능을 금지한다. 여는 방법을 심사 메모에 적어 두면 '숨긴 기능' 이 아니라
'설명된 기능' 이 된다. 적지 않고 발견되면 반려 사유가 된다.

> 설정 화면의 버전 번호를 12번 누르면 탐색 탭에 '지상파' 갈래가 나타납니다.
> 한국 지상파 라디오를 듣는 기능이며, 1.7 사용자가 쓰던 기능을 이어받은 것입니다.

함께 적을 것.

- **백그라운드 오디오** — 인터넷 라디오와 팟캐스트를 화면을 끈 채 듣는 앱이다.
- **Time Sensitive Notifications** — 알람 기능이라 집중 모드에서도 떠야 한다.
- **알람은 탭해야 소리가 난다** — iOS 제약을 인정한 설계다(`docs/01-features.md` 5.1).
  시계 앱처럼 저절로 울리지 않는다는 점을 적어 둔다.
- **방송 콘텐츠** — 스트림을 그대로 재생하고 방송국 광고를 지우지 않는다. 방송국 정보와
  홈페이지 링크를 표시한다(`docs/05-ads-policy.md` 4번).

## 4. AdMob 콘솔에서 할 일

1. 앱을 등록한다. 번들 ID `com.zerolive.cloudRadioN`.
2. 앱 ID(`ca-app-pub-…~…`)를 받아 `Secrets.xcconfig` 의 `ZP_ADMOB_APP_ID` 에 넣는다.
3. 배너 광고 단위를 넷 만든다 — 추천·탐색·프리셋·기록. 각각 `ZP_ADMOB_BANNER_*` 에 넣는다.
4. **동의 메시지를 한국어로 만든다.** 지금 쓰는 구글 테스트 계정에는 영어 ATT 사전 안내가
   모든 지역에 걸려 있어 앱을 열자마자 영어 창이 뜬다. 실제 계정에서는 EEA·영국에만
   동의창이 필요하고, 한국 사용자에게는 아무 창도 뜨지 않는다.

값을 넣기 전에도 배너는 뜬다. 기본값이 구글 테스트 ID 라 계정 없이 배치를 확인할 수 있다.

## 5. 앱 쪽 점검

- [ ] 실기기에서 배너가 네 화면에 뜨고, 재생 화면·미니 플레이어·지상파·알람 직후에는 안 뜬다
- [ ] ATT 허가창이 한 번만 뜨고, 거부해도 배너가 계속 나온다
- [ ] `Secrets.xcconfig` 에 실제 AdMob ID 를 넣고 빌드하면 설정 화면의 '테스트 단위' 표시가 사라진다
- [ ] 1.7 에서 업데이트했을 때 알람·히든 해제·채널 목록이 그대로 옮겨진다
- [ ] 유튜브 안내가 한 번만 뜬다
- [ ] 글자 크기를 가장 크게 해도 화면이 깨지지 않는다
- [ ] VoiceOver 로 재생·일시정지·프리셋 실행을 할 수 있다
